## 2. Layering

```
HTTP ─► routers (app/api) ─► gateway (mock | live) ─► services ─► repositories ─► SQLAlchemy models
                                                   └─► engine (pure functions, no I/O) ◄─ ml/predictor
```

- **Routers** only parse/validate, resolve the `Principal`, call the gateway and wrap the result with `ok()`.
- **Gateway** (`app/services/gateway.py`) chooses `MockGateway` (MOCK_MODE=true) or the live gateway.
  Both expose identical method signatures returning identical Pydantic types — that is what guarantees
  the mock and live JSON are schema-identical.
- **Engine** (`app/engine`, Phase 4–5) is pure functions over plain dataclasses: unit- and property-testable,
  and every formula is surfaced via `/api/v1/system/methodology`.
- **ML plug-in**: `app/ml/predictor.py::predict_domain_fit(vector)`; falls back to a deterministic
  centred-cosine against 12 domain prototypes when no model is configured or the model errors.

## 3. Response envelope

```json
{
  "success": true,
  "data": { "...": "..." },
  "error": null,
  "meta": { "request_id": "9f1c…", "version": "v1/0.1.0", "mock": true }
}
```
Errors: `{"success": false, "data": null, "error": {"code": "NOT_FOUND", "message": "...", "details": {}}, "meta": {...}}`.
Codes: `VALIDATION_ERROR 422, INCOHERENT_INPUT 422, UNAUTHORIZED 401, FORBIDDEN 403, CONSENT_REQUIRED 403,
NOT_FOUND 404, CONFLICT 409, RATE_LIMITED 429, LIVE_MODE_UNAVAILABLE 501, INTERNAL_ERROR 500`.
Every response carries `X-Request-ID` (echoed if the client sends a sane one) and `X-Response-Time-ms`.

## 5. MOCK_MODE

- `MOCK_MODE=true` (default): every endpoint returns fixtures from `app/mocks/` built **through the same
  Pydantic models**; `meta.mock=true`. No database needed.
- Role-specific views can be exercised without auth by sending `X-Mock-Role: student|parent|educator|admin`.
- `MOCK_MODE=false` in this build returns `501 LIVE_MODE_UNAVAILABLE` for everything except
  `/system/health` and `/system/methodology`; live services land phase by phase.
- Static copies for the frontend: `backend/contracts/fixtures/*.json` (+ `_index.json`) and
  `backend/contracts/openapi.json`, regenerated by `python scripts/export_contracts.py`.
